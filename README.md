# Yuri's Chamber

Discord bot for **BANORANT CAFE🎮** (Filipino Valorant community).

## Core features
- Verification (age / gender / rank)
- Welcome & goodbye
- Leveling + `/rankupdate`
- Birthday roles
- Owner web dashboard + AI (`/prompt`, bot DMs)
- Channel locks, moderation, giveaways (optional)

## Run
1. Set env: `DISCORD_TOKEN`, `CLIENT_ID`, `GUILD_ID`, `OWNER_IDS`, Firebase creds, `NAGA_API_KEY` / AI keys, dashboard login
2. `npm install`
3. `npm start`

## Notes
Originally adapted from an open-source modular bot codebase; branding and features are customized for BANORANT CAFE🎮.
